microvms-app and microvms-core move to zip 9, whose entry `name()` and `ZipArchive::file_names()` now return a `Result`. Only test code reads entry names (the tests in `crates/microvms-app/src/control/artifact.rs` and `crates/microvms-core/tests/bdd_ensure.rs`); the image build only writes, and the artifact it writes is byte-identical under zip 8.6.0 and 9.0.3 for the same inputs, so no user of the crates, the CLI or the bindings can observe the change.
