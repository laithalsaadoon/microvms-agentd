- **The daemon reports the release number as its version (#592).** The 1.0.0 `agentd` reported
  `0.1.0` in `GET /v1/health`, the `microvms-agentd-version` header, `/v1/schema`'s
  `daemon_version` and its startup log, because its crate version never moved with a release. It
  now carries the release number, and `release:tag` refuses a release whose daemon version
  differs from the tag. `PROTOCOL_VERSION` stays 2, so a client that compares only it proceeds
  as before.
