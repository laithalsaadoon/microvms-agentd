  region without MicroVMs always answers with a null-message `AccessDeniedException`, or that
  such a message rules out IAM (#743).** The `Region` doc comments in both bindings, which
  `microvms.pyi` and `index.d.ts` carry, call the five regions the ones this client lists and say
  AWS runs MicroVMs in more, which `Region.unlisted` reaches. The refusal for an unlisted region
  name and the `--unlisted-region` help say a region without MicroVMs can answer with that
  denial. The CLI's suggestion for a credentials failure names both causes of a null-message
  `AccessDeniedException`, a region without MicroVMs or an IAM denial of an implied action, and
  still says to check `--region` first. The error for a region the rate catalog has no line items
  for says the same. The client still lists the same five regions.
