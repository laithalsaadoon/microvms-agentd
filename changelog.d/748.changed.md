- **The npm package's loader comes from @napi-rs/cli 3.10.9 (#748).** It exports the same
  names, and `index.d.ts` and the addons are byte-identical to 3.10.8's. Two loading paths
  changed: on FreeBSD ppc64, a platform this package publishes no addon for, the loader now
  looks for one before it fails; and when a package-level fallback swaps the native binding
  for a generated WASI loader, `__napiBindingTarget` reports that loader's flavor, where it
  reported `'native'`.
